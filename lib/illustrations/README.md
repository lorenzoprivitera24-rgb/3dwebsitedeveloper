# Illustrations — vendored offline SVG art shelf

The free, self-hostable stand-in for [Blush](https://blush.design). Blush is a paid SaaS that serves
PNGs one-at-a-time behind a login and can't be bulk-downloaded — so instead of Blush we vendor the
**open sets the same creators/community published**: unDraw's editorial scenes, DiceBear's 31
avatar/doodle/abstract styles (generated locally), Pablo Stanley's Open Doodles and Humaaans
(mirrored). Nothing loads from a third-party CDN at runtime (GDPR — everything here is already a local
file). See the full list in [`CATALOG.md`](CATALOG.md).

## What / why

- **What — four sources, 2883 SVG + Humaaans:**
  - **unDraw** — 1362 editorial "real scene" SVGs (heroes, empty states, feature blocks). *The
    biggest and most useful set for page art.*
  - **DiceBear** — 1488 avatar/doodle/abstract SVGs (31 styles × 48 deterministic variants).
  - **Open Doodles** — 33 hand-drawn people scene doodles.
  - **Humaaans** — 79 SVG + 158 PNG mix-and-match people pieces.
  - All flat 2D — no WebGL, no runtime deps.
- **Why:** hero/section art, empty/error/onboarding states, feature blocks, and illustration you can
  texture onto R3F planes — without a paid tool and without a CDN call.

## The three tiers of obligation

The whole shelf is free to ship. What varies is what you owe on ship:

| Tier | Sets | Obligation |
|---|---|---|
| **(i) No attribution & unrestricted** | DiceBear CC0 / MIT / free-P+C styles (Glass, Lorelei, Open Peeps, Notionists, Pixel Art, Bootstrap Icons, Avataaars, Bottts, …) + **Open Doodles** (CC0) | **None.** Use freely, no credit, no conditions. |
| **(ii) No attribution BUT restricted** | **unDraw** (1362) | **No credit required**, BUT: no repackaging as a standalone pack/library, and no AI/ML training. Static graphics in a delivered site = fine. See [`undraw/LICENSE.md`](undraw/LICENSE.md). |
| **(iii) Attribution required** | 13 CC BY 4.0 DiceBear styles (Adventurer, big-ears/`Face Generator`, big-smile/`Custom Avatar`, Croodles, Dylan, Fun Emoji, Micah, Miniavs, Personas, ToonHead) + **all of Humaaans** | **Must credit** → paste the block from [`ATTRIBUTION.md`](ATTRIBUTION.md). |

Which set is which tier is in [`CATALOG.md`](CATALOG.md) and, per DiceBear style, in
`dicebear/<style>/meta.json`. When in doubt, reach for a tier-(i) set and you owe nothing.

## Theming, in one line each

- **unDraw** → set the accent globally with the CSS variable `--primary-svg-color` (only resolves when
  the SVG is **inlined into the DOM**, not via `<img src>`). See [`undraw/README.md`](undraw/README.md).
- **Open Doodles** → two baked colors: swap ink `#000000` and accent `#FF5678` by find/replace.
- **DiceBear** → deterministic seeds (filename = seed); regenerate with different seeds/options, don't
  hand-edit.

## Regeneration

The DiceBear set is generated (deterministic seeds — re-running reproduces byte-identical output):

```bash
node scripts/gen-illustrations.mjs                 # all 31 styles, 48 variants each
node scripts/gen-illustrations.mjs --count 96      # more variants per style
node scripts/gen-illustrations.mjs openPeeps lorelei --count 60   # only these styles
```

Each run rewrites the style folders, their `meta.json`, and `dicebear/manifest.json`.

unDraw, Open Doodles and Humaaans are **static mirrors** (not generated by the script). To re-vendor:

```bash
# unDraw — mirror repo; keep OUR undraw/LICENSE.md, NOT the mirror's mislabeled MIT one
git clone --depth 1 https://github.com/balazser/undraw-svg-collection.git /tmp/undraw-src
cp /tmp/undraw-src/svgs/*.svg lib/illustrations/undraw/svg/

# Open Doodles — generated from the React component source (see open-doodles/README.md)
git clone --depth 1 https://github.com/lunahq/react-open-doodles.git
# extract each <svg>…</svg>, replace ={ink}→"#000000" and ={accent}→"#FF5678", convert JSX attrs to SVG.
```

**Humaaans is not regenerated** — it's a plain static mirror of the open pack; leave it as-is.
