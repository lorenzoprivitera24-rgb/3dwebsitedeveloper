# Attribution — illustrations

Include the block below **only if the shipped site actually uses one or more CC BY 4.0 sets** from this
shelf. CC BY 4.0 requires crediting the creator, naming the license, and linking it. Drop the credit in
a site footer, an `/credits` page, an About/Colophon, or a `NOTICE`/`CREDITS` file — any reasonably
visible place is fine under the license.

The **only** sets on this shelf that require attribution are the **13 CC BY 4.0 DiceBear styles** and
**Humaaans**. Everything else needs **no credit**:

- **CC0 1.0 / MIT / "Free for personal and commercial use"** — DiceBear styles (Glass, Identicon,
  Initials, Lorelei, Notionists, Open Peeps, Pixel Art, Rings, Shapes, Thumbs, Bootstrap Icons,
  Avataaars, Bottts) **and Open Doodles** (CC0). Ship these with **zero credit**, no conditions.
- **unDraw** (1362 editorial scenes) — **no attribution required** either (see the note below), **but**
  unlike the CC0/MIT sets it carries its own restrictions. Read the unDraw note before you assume it's
  unconditional.

## No attribution, but read this — unDraw

**unDraw needs NO attribution** — but it is **not** CC0/MIT, and it has restrictions the credit-free
sets above don't. Per [`undraw/LICENSE.md`](undraw/LICENSE.md) (unDraw's own license, **not** the
mislabeled MIT `LICENSE` some mirror repos ship):

- ✅ Free for personal and commercial use, no credit required, modify/recolor freely, ship inside the
  sites you deliver.
- ❌ **No repackaging** — don't re-publish `lib/illustrations/undraw/` as a standalone pack, npm
  package, GitHub asset bundle, or any competing illustration service. Keep it internal to this kit.
- ❌ **No AI/ML training** — don't feed the assets to model training/fine-tuning. Static graphics in a
  site are fine.

So: no line in the credit block above, but honor the two restrictions.
